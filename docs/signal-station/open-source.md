# Public source access

The [Android repository](https://github.com/ambient-time/pebble-inspector-companion)
is public. Its default branch is `codex/signal-station`, which contains the
standalone app and current documentation. The earlier `inspector-lab` branch
and its separate CI work remain intact.

Luke Steuber's original contributions have an MIT grant. The inherited Core
Devices software retains GPLv3 and its other notices. See
[licensing scope](../../LICENSING.md); the whole fork is not MIT-only.

The [download page](https://dr.eamer.dev/downloads/apps/signal-station/) links to
both repositories and the published installers and source ZIPs. Repository HEAD
can be newer than an installer. Release checksums and source commits identify
the corresponding build.

Read [the developer guide](development.md) to build the standalone app. The
upstream documentation covers separate host and iOS targets. Publishing source
adds no new Android or physical-watch test results; existing acceptance notes
retain their original scope.
