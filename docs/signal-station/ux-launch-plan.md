# UX preview launch

By Luke Steuber. September 11, 2026.

Approved target: public Android preview 0.4.0-ux-dev (11). Preserve the package,
preview certificate, source keys, encrypted history and Pebble installation hold.

Now / Ask / History remain the main destinations. Now offers Capture now,
Around me and Record over time, selected sources and a useful saved result.
Around me groups Signals, Places and My devices. Ask keeps its composer
reachable, attachments visible and Review separate from Send. Saved questions
move into Ask; recordings and patterns remain under History. Capture tools
becomes contextual collection presets, comparisons and advanced field trials.
Settings groups Sources and permissions, Answers, Connected devices, Voice,
Learning and privacy, and Storage. Return navigation preserves task context.

Shared typed history queries span the full store. Date limits describe record
capture/save time in the chosen timezone. Query/explicit selections freeze
record IDs and revisions for actions; narrowed source scopes project readings
and omit broad prose. Model review remains bounded with explicit omissions.
Scoped exports contain selected evidence only, while all-data export stays a
separate action. Deletion or source/evidence changes invalidate prepared actions.
Saved question scopes are optional fields with legacy-compatible defaults.

Live detail inspection freezes its content and survives expiry. Live scanning
stops on leaving, pane changes, source changes and backgrounding; no automatic
restart. Timed recording stays visibly distinct. Permissions and provider setup
return to the originating task. No sensor, online request or model send is
implicitly enabled by presets or navigation.

Acceptance: capture-inspect, live permission recovery and expiry, recording
lifecycle, scoped comparison/export, and attach-provider setup-review-send.
Validate host/integration tests, Android lint, APIs 28/31/36, 200% text, narrow
layout, keyboard and TalkBack. Upgrade published build 10 in place. Freeze source,
verify signing and APK identity, update guide and download copy, stage on mounted
Galactus, publish through the existing toolkit and audit both public domains.
Commit and push all reviewed app/toolkit/site files, verify remote heads, and
record measured evidence separately from unavailable physical-device checks.
